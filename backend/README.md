\# Revenue Recovery Agent



AI-powered agent that recovers revenue from failed payments, abandoned checkouts, and overdue invoices.



\## Features

\- AI-powered payment failure diagnosis

\- RAG-based context retrieval

\- Circuit breaker safety

\- Real-time recovery dashboard

\- Complete audit trail



\## Usage

1\. Click "Run Agent Batch" to start recovery

2\. Refresh dashboard to see updated stats

3\. View transaction details and audit trail



\## Tech Stack

\- \*\*Backend\*\*: FastAPI, LangChain, Groq

\- \*\*Frontend\*\*: React, Vite

\- \*\*Database\*\*: SQLite

\- \*\*LLM\*\*: Groq (openai/gpt-oss-120b)
